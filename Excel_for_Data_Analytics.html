2 Data Entry & Basic Formulas 🔥 Must-Know2_set.txt

Real-world data is messy — extra spaces, wrong capitalization, blank rows, values glued together. Cleaning it up is one of the most common jobs a data analyst does, often taking more time than the actual analysis. Master this section first.

💼 Why your manager cares Manager says: "This export looks messy, can you clean it up before the report goes out?" The goal: turn raw data pulled from a system, another team, or a form into something reliable enough to build formulas and reports on top of. This is the invisible first step behind almost every deliverable you'll ever hand over.

Insert / Delete Rows & Columns

  • Select the column after where the new one should go, then press Ctrl++ to insert a blank column before it.
  • Ctrl+- deletes the selected column.
  • Same idea works for rows.

Selection Shortcuts (selects only the data, not the whole sheet)

Ctrl+Shift+→ select across all columns of data
Ctrl+Shift+↓ select down all rows of data
Ctrl+A select the whole data block at once

Cell Formatting

Change how a date/number is displayed: Ctrl+1 opens Format Cells.

Relative vs. Absolute Reference 🔥 Must-Know

Think of it like giving directions: a relative reference is "turn left at the next corner" — it shifts depending on where you start. An absolute reference (locked with $) is a GPS coordinate — it always points to the exact same cell, no matter where you copy the formula. 
=SUM(H5:J5)+$H$16
Formula in rowWhat it becomes when copied downWhy
Row 5=SUM(H5:J5)+$H$16H5:J5 is relative — matches its own row
Row 6=SUM(H6:J6)+$H$16H6:J6 shifted down, but $H$16 stayed locked
Row 7=SUM(H7:J7)+$H$16Same pattern — $ signs freeze the row/column

Conditional formatting was also introduced here — it highlights cells automatically based on rules (e.g. color all values below target red). Great for spotting outliers at a glance.

Data Cleaning for Analysis 🔥 Must-Know

Messy text breaks lookups and filters silently — "Delhi" and "Delhi " (extra space) look identical to a human but are different to Excel.

  • Remove blank rows: Ctrl+G (Go To Special) → select Blanks → Ctrl+- to delete them.
=LEN(text)     → counts characters (helps you spot hidden extra spaces)
=TRIM(text)    → strips leading/trailing spaces
=SUBSTITUTE(A2,CHAR(160),"")   → removes an "unbreakable" space (a space that looks
                                   normal but is a different character, code 160)

Fixing capitalization:

=PROPER(text)   → Capitalizes Each Word
=UPPER(text)    → ALL CAPS
=LOWER(text)    → all lowercase

Ternary-style IF 🔥 Must-Know

A quick way to say "if this, do A, otherwise do B" in one cell.

=IF(E2<0,0,E2)
Plain English: IF E2 is less than 0 → show 0, OTHERWISE → show E2 as-is.
Example use: sales returns sometimes get entered as negative numbers by mistake — this formula caps them at 0 instead of letting negatives distort a total.
E2 = -50 → result 0  |  E2 = 120 → result 120

Splitting Data — Flash Fill & FIND/LEFT/RIGHT 🔥 Must-Know

Example value: DELHI-110059. Type the split-out part into the next column by hand once, then press Ctrl+E — Excel detects the pattern and auto-fills the rest of the column.

Or split it with a formula, which is more reliable for large or changing datasets:

=FIND("-",A2,1)                     → position of the hyphen (here: 6)
=LEFT(A2,FIND("-",A2,1)-1)          → "DELHI"
=RIGHT(A2,LEN(A2)-FIND("-",A2,1))   → "110059"
Example: splitting an email into username + domain

Value: aarav.sharma@company.com

=LEFT(A2,FIND("@",A2)-1)          → "aarav.sharma"
=RIGHT(A2,LEN(A2)-FIND("@",A2))   → "company.com"

Data Validation ⭐ Frequently Used

Menu path: Alt → A → V → V

Restricts what can be typed into a cell (e.g. a dropdown of valid states). This stops messy variants like "Maharashtra" / "maharashtra " / "Maharastra" from ever entering the sheet — which is exactly what would otherwise break SUMIF, COUNTIF and VLOOKUP later.

Logical Functions — IF, IFS, AND, OR 🔥 Must-Know

=IFS(D2>75000,D2*0.2, D2>50000,D2*0.15, D2<=50000,D2*0.1)

Plain English: check conditions top to bottom, and use the calculation next to the first one that's true — like a tidier stack of nested IFs.

Example: commission tiers using the IFS formula above
Sales (D2)Condition matchedCommission
90,000D2 > 75000 → 20%18,000
60,000D2 > 50000 → 15%9,000
40,000D2 <= 50000 → 10%4,000

AND = every condition must be true. OR = at least one condition must be true.

=IF(AND(B2=G$4,C2>=5),"Yes","No")   → "Yes" only if BOTH match
=IF(OR(B2=G$4,C2>=5),"Yes","No")    → "Yes" if EITHER matches

Sorting ⭐ Frequently Used

Menu: Alt → A → S → S, or by formula (spills results automatically, source data untouched):

=SORT(A2:J1001,2,-1)   → sort the range by column 2, descending (-1)

Filtering ⭐ Frequently Used

Menu: Alt → A → T, or by formula:

=FILTER(A2:J1001,D2:D1001="Maharashtra")   → only rows where column D = "Maharashtra"

Tip: pair a Data Validation dropdown cell with SORT/FILTER formulas so a user can just pick a state/category from a list and the report updates instantly.

TAKE — Top N Rows 📘 Good to Know (newer Excel/365 function)

=TAKE(A2:J1001,7)   → keeps just the first 7 rows

Combining TAKE + SORT + FILTER 🔥 Must-Know for dynamic "Top N" reports

Question: "Show the top 5 customer transactions from Maharashtra."

=TAKE(SORT(FILTER(A2:J1001,D2:D1001=M2),N2,-1),O2)

Read it inside-out: FILTER() keeps only Maharashtra rows → SORT() arranges them biggest-first → TAKE() keeps only the top 5. This one-line pattern (TAKE( SORT( FILTER() ) )) replaces what used to need a pivot table + manual sort, and it updates live if the source data changes.

COLUMN() simply returns the current column's number — handy inside bigger dynamic formulas.

3 VLOOKUP, MATCH & INDEX 🔥 Must-Know3_set.txt

One of the most frequently used — and most frequently interviewed — Excel skills for data roles. If you only deeply learn one topic on this page, make it this one.

💼 Why your manager cares Manager says: "Can you add each customer's region next to their order?" or "Match up the salary column from HR's file with our project list." The goal: combine information that lives in two different sheets/tables using a shared ID — this is basically doing a manual database JOIN inside Excel, and it's asked for constantly.

VLOOKUP — Vertical Lookup

Think of a phone book: you know the person's name (lookup value), and you flip to their row to read off their phone number (a value sitting in another column of that same row). VLOOKUP does exactly this, automatically.
=VLOOKUP(lookup_value, table_array, col_index_num, range_lookup)
  • 1. lookup_value — what you're searching for, e.g. an employee ID.
  • 2. table_array — the whole table to search in. The value you're searching for must be in its left-most column.
  • 3. col_index_num — which column to return, counted from 1 starting at the left edge of table_array.
  • 4. range_lookup — TRUE/1 = closest match, FALSE/0 = exact match only (use this almost always).
If using TRUE (approximate match), the table must be sorted ascending by the lookup column, or you'll get wrong results silently — no error shown.
Worked example — using the Employees table (3_set.xlsx)

Find the salary of employee EMP005:

=VLOOKUP("EMP005", A2:D21, 4, FALSE)   → 85000

Column 1 = Employee_ID, 2 = Name, 3 = Department, 4 = Salary — so col_index_num = 4 returns the salary.

Common error — #N/A: means Excel could not find an exact match. Usual causes: a typo, an extra space (run TRIM() first), the lookup value is a number stored as text (or vice versa), or you searched for something not in the left-most column.

MATCH — Find a Position, Not a Value

MATCH tells you where something is, instead of what value is next to it.

=MATCH(H4,A1:E1,0)   → returns the column number where H4's value is found (0 = exact match)

INDEX — Value by Row & Column Number

=INDEX(A1:J9,C19,D19)   → the value sitting at row C19, column D19 inside A1:J9
Worked example — INDEX + MATCH together

Find the department of employee EMP010 (Department is column C):

=INDEX(C2:C21, MATCH("EMP010", A2:A21, 0))   → "Marketing"

MATCH finds EMP010 is the 9th row in the ID list; INDEX then returns the 9th value in the Department column.

VLOOKUP + MATCH — Dynamic Column Lookup

Nesting MATCH inside VLOOKUP means the column number is found automatically instead of typed as a fixed number — so it still works if columns get reordered:

=VLOOKUP($I$3,our_table,MATCH(H4,$A$1:$E$1,0),0)
Why data analysts often prefer INDEX+MATCH (or XLOOKUP) over plain VLOOKUP:
• VLOOKUP can only search left-to-right — the lookup column must be the left-most one in the range.
• VLOOKUP breaks (returns wrong values) if someone inserts a new column inside the table, because col_index_num no longer points where you think.
• INDEX+MATCH can look in any direction and survives inserted columns.
• XLOOKUP (newer Excel/365 function) does everything VLOOKUP and INDEX+MATCH do, more simply: =XLOOKUP(lookup_value, lookup_array, return_array) — worth learning once you're comfortable with VLOOKUP.

4 Statistical Formulas 🔥 Must-Know4_SET.TXT · Ch.7

These are the everyday formulas behind quick KPIs and summary numbers — "total sales in Delhi," "how many orders last month," etc. Analysts write these constantly, often faster than opening a pivot table for a one-off number.

💼 Why your manager cares Manager says: "What's our total sales in the North region?" or "How many customers did we lose last month?" The goal: give a fast, precise, one-off answer to a specific question without having to build a whole pivot table — perfect for when someone asks a quick number in a meeting or over chat.

The IF-Family of Aggregations — Plain Syntax

=COUNTIF(range, criteria)                          → count cells matching ONE condition
=COUNTIFS(range1,crit1, range2,crit2, ...)          → count matching MULTIPLE conditions

=SUMIF(range, criteria, sum_range)                  → add up numbers matching ONE condition
=SUMIFS(sum_range, range1,crit1, range2,crit2, ...) → add up numbers matching MULTIPLE conditions

=AVERAGEIF(range, criteria, avg_range)              → average matching ONE condition
=AVERAGEIFS(avg_range, range1,crit1, ...)           → average matching MULTIPLE conditions

=MAXIFS(max_range, range1,crit1, ...)               → largest value matching conditions
=MINIFS(min_range, range1,crit1, ...)               → smallest value matching conditions
The #1 mix-up beginners make: in SUMIF, sum_range comes last. In SUMIFS (and every other "...IFS" function), the range to summarize comes first. Getting this backwards is the most common reason these formulas silently return 0 or an error.
Worked example — small sales dataset
RowStateProductQty
2MaharashtraLaptop5
3MaharashtraMouse3
4GujaratLaptop2
5MaharashtraLaptop4
=COUNTIF(B2:B5,"Maharashtra")               → 3   (3 rows match)
=SUMIF(B2:B5,"Maharashtra",D2:D5)           → 12  (5+3+4)
=SUMIFS(D2:D5,B2:B5,"Maharashtra",C2:C5,"Laptop")  → 9   (5+4, Maharashtra AND Laptop only)

Q1 — Total transactions by each state

"Total transactions" here means the count of rows, not the sum of price.

=COUNTIF(state_range, state_name)

Q2 — Total transactions by state AND product category

=COUNTIFS($D$1:$D$1001,$L11,$F$1:$F$1001,M$10)

Q3 — Total quantity sold by region

=SUMIF($E:$E,$L21,$H:$H)

Q4 — Total quantity sold by region AND product name

=SUMIFS($H:$H,$G:$G,$L28,$E:$E,M$27)

5 Date Formulas ⭐ Frequently Used5_set.txt

Dates show up in almost every dataset — signup dates, order dates, deadlines. Analysts use these to build reporting periods, calculate tenure/age, and check working days.

💼 Why your manager cares Manager says: "How long has this employee been with us?" or "Just show me this month's numbers." The goal: work with time correctly — ages, tenure, deadlines, reporting windows — since almost every business report is sliced by some time period, and date bugs (off-by-one days, wrong month) are an easy way to lose credibility.
DAYMONTHYEARDATETEXTEOMONTHDATEDIFNETWORKDAYS.INTL

Rebuild / Fix a Date

Useful when a date was imported as text or in a broken format — this rebuilds it as a real Excel date.

=DATE(YEAR(B2),MONTH(B2),DAY(B2))

Difference Between Two Dates

=D2-C2   → number of days between the two dates

Today's Date

=TODAY()

Age From Date of Birth ⭐ Frequently Used

=DATEDIF(D2,TODAY(),"Y")

Example: if D2 = 15-Mar-1995 and today is 06-Jul-2026, this returns 31 (full completed years).

Full Y/M/D breakdown (concatenating text with &):

=DATEDIF(D2,TODAY(),"Y")&"Years "&DATEDIF(D2,TODAY(),"YM")&" Months "&DATEDIF(D2,TODAY(),"MD")&"Days"

"YM" = leftover whole months after the years, "MD" = leftover whole days after that — gives a clean "31 Years 3 Months 21 Days" instead of one big number.

Format a Date with TEXT()

=TEXT(D11,"DD-MMM-YYYY")

6/25/2026  →  25-Jun-2026

Handy for reports/exports where a specific date format is expected (e.g. matching a client's spreadsheet format).

EOMONTH — End of Month

Returns the last date of a month, N months from a starting date. Great for building month-end reporting cutoffs automatically.

=EOMONTH(D1,2)

D1 = 15-Jan-2026  →  31-Mar-2026   (end of month, 2 months ahead)

NETWORKDAYS.INTL — Working Days

Counts working days between two dates. "INTL" (International) lets you customize which days count as weekend and supply a holiday list — useful because not every country/company treats Sat+Sun as the only days off.

=NETWORKDAYS.INTL(start_date, end_date, weekend_code, holidays_range)
=NETWORKDAYS.INTL(A2,A32,11,E2:E3)

6 Pivot Tables 🔥 Must-Know6_SET.TXT

Arguably the single most-used reporting tool in a data analyst's toolkit — it turns thousands of raw rows into a clean summary table in seconds, with no formulas at all. The original class notes here were very brief, so this section has been expanded with the core workflow every analyst needs.

💼 Why your manager cares Manager says: "Give me a summary — sales by region and by month" or "Break this down by product category." The goal: turn a giant flat spreadsheet into a clean, digestible summary a non-technical person can actually read in ten seconds. This is the #1 tool for turning raw data into "a report."

What It Is

A drag-and-drop feature that groups and summarizes your data. Instead of writing a SUMIF for every state, or a COUNTIF for every category, you drag the field names into four boxes and Excel builds the whole summary table for you.

The Four Areas

  • Rows — categories to list down the side (e.g. Region, Product).
  • Columns — a second category spread across the top (e.g. Year), so you get a grid.
  • Values — the numbers to summarize, and how (Sum, Count, Average, Max, Min).
  • Filters — an extra field used to slice the whole table (e.g. show only 2026 data).
Worked example — replacing several SUMIF formulas with one pivot table

Using the same sales data as the Statistical Formulas section (State, Product, Qty):

  1. Click anywhere in the data, then Insert → PivotTable.
  2. Drag State into Rows.
  3. Drag Qty into Values (defaults to Sum).

Result — one row per state with its total quantity, instantly, with no SUMIF formula written at all:

StateSum of Qty
Maharashtra12
Gujarat2

Drag Product into Columns as well, and you instantly get a State × Product grid — the same result as the "region AND product" SUMIFS/COUNTIFS formulas from Topic 4, without typing a formula.

Changing Sum to Count / Average

Right-click any number inside the pivot table → Value Field Settings → choose Sum, Count, Average, Max, or Min.

Grouping Dates 🔥 Must-Know for time-series reporting

If a date field is in Rows, right-click any date → Group → choose Months / Quarters / Years. This turns a column of 1,000 individual dates into a clean Month-by-Month or Quarter-by-Quarter summary instantly — one of the fastest ways to build a trend report.

Refreshing Data

Important: a pivot table does NOT update automatically when the source data changes. After adding/editing rows, right-click the pivot table → Refresh (or press Ctrl+Alt+F5) to pull in the latest data.

Slicers & Pivot Charts

  • Slicers — clickable filter buttons (a friendlier alternative to the Filters box) that let anyone filter the report visually.
  • PivotChart — one click turns the same pivot table into a chart that stays in sync with it automatically.

7 Charts & Data Visualization 🔥 Must-Know+ Added Topic

Numbers in a table prove a point; a chart is what people actually remember and act on. Turning analysis into a clear visual is one of the most direct ways your work reaches decision-makers.

💼 Why your manager cares Manager says: "Can you turn this into something I can put in the slide deck?" The goal: communicate a trend or comparison visually — a chart gets understood (and remembered) by non-technical stakeholders in seconds, where a table of numbers would take them minutes.

Choosing the Right Chart

  • Line chart — a trend over time (e.g. sales by month).
  • Bar / Column chart — comparing categories side by side (e.g. sales by region).
  • Pie chart — share of a whole. Use sparingly — keep it to about 5 slices or it becomes unreadable.
  • Scatter plot — the relationship between two numeric variables (e.g. price vs. quantity sold). Heavily used in data science to visually spot correlation before running any formula.
  • Combo chart — two different measures together (e.g. revenue as bars + growth % as a line on a second axis).

Building One

Select your data → Insert tab → pick a chart type from the Charts group. Then add a clear title, label the axes, and remove clutter (unnecessary gridlines, an unneeded legend) — a clean chart reads faster than a busy one.

Sparklines 📘 Good to Know

Tiny in-cell charts (Insert → Sparklines) that fit inside a single cell — useful for showing a mini-trend next to every row in a dashboard without taking up space.

Pair this with Topic 6 — building a PivotChart from a pivot table gives you a chart that updates automatically whenever the underlying pivot table refreshes.
Example: spotting a trend
MonthJanFebMarAprMayJun
Sales1201351289095110

A line chart of this row instantly shows the Q2 dip (Apr–May) that's much harder to notice by scanning raw numbers — exactly the kind of insight a manager wants flagged, not buried in a table.

8 Power Query — Get & Transform Data 🔥 Must-Know+ Added Topic

Once your data starts coming from multiple files, folders, or systems, cleaning it by hand every single time doesn't scale. Power Query is the modern data analyst's answer to that — and it's one of the biggest productivity jumps you can make.

💼 Why your manager cares Manager says: "We now pull this data from three different systems — can you combine them into one report every week?" The goal: automate the painful, repetitive part of the job (pulling, cleaning, and merging data from multiple sources) so you're not manually redoing the same cleanup steps every single week.
Think of it like a recorded recipe: you show Excel once how to clean and reshape the data — remove a column, fix a data type, split a field. Power Query remembers every step. Next week's file just gets poured through the same recipe with one click.

Where to Find It

Data tab → Get Data / Get & Transform — import from an Excel/CSV file, a whole folder of files, a database, or a web page.

Key Operations

  • Remove Duplicates / Remove Errors — clean bad rows in one click.
  • Change Type — force a column to be a proper number/date/text so later formulas don't break.
  • Split Column — the point-and-click version of the FIND/LEFT/RIGHT trick from Topic 2.
  • Merge Queries — combine two tables side-by-side using a matching column, like a VLOOKUP that merges the entire table at once (this is literally a JOIN).
  • Append Queries — stack multiple files with the same columns into one long table (e.g. combining 12 monthly export files into one year of data).

Why It Beats Manual Cleaning

Every click you make is recorded as a named step in the Applied Steps panel — so your cleaning process is documented, repeatable, and auditable. When new data arrives in the exact same format, you just hit Refresh instead of repeating 15 manual steps.

9 XLOOKUP & Dynamic Arrays 🔥 Must-Know+ Added Topic

Newer Excel/365 functions that solve the same problems as VLOOKUP/SORT/FILTER, but more simply and with fewer ways to break. Worth learning right after you're comfortable with Topic 3.

💼 Why your manager cares Manager says: "Give me a list of all our unique customers" or "Find this value even though the list isn't sorted." The goal: more flexible, less error-prone lookups and lists that adapt automatically as the data grows — important once you're working with live, constantly-changing datasets instead of a one-time snapshot.

XLOOKUP — the Modern VLOOKUP

=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found])
  • No column counting — you point straight at the column you want returned.
  • Searches left or right (VLOOKUP only searches right of the lookup column).
  • Built-in "not found" message instead of a bare #N/A.
=XLOOKUP("EMP005", A2:A21, D2:D21, "Not Found")   → 85000

UNIQUE — Instant Distinct List

=UNIQUE(D2:D1001)   → spills a list of every distinct state, automatically

No more manual "Remove Duplicates" — this formula recalculates the unique list live whenever the source data changes.

SORTBY — Sort One List by Another

=SORTBY(name_range, sales_range, -1)   → names sorted by sales, highest first

SEQUENCE — Auto-Generate Numbers

=SEQUENCE(10)          → 1,2,3...10 down a column
=SEQUENCE(1,12)        → 1,2,3...12 across a row (e.g. month numbers)
These are "spill" formulas — one formula automatically fills every cell it needs. If you see #SPILL!, something (usually a stray value) is sitting in a cell the result needs to expand into — clear that cell and it resolves.

10 Basic Statistics, Correlation & Forecasting 🔥 Must-Know+ Added Topic

This is the bridge between reporting what happened (data analyst) and explaining why it happened or predicting what happens next (data science / ML). Even before opening Python or R, most of these questions can be sanity-checked directly in Excel.

💼 Why your manager cares Manager says: "Is there a relationship between marketing spend and sales?" or "What do you expect next quarter's numbers to look like?" The goal: move past just describing what happened, into explaining relationships between variables and predicting what's likely to happen next.

Describing a Dataset

=AVERAGE(range)         → the typical value
=MEDIAN(range)          → the middle value (less skewed by extreme outliers than AVERAGE)
=STDEV.S(range)         → how spread out the values are (sample data)
=QUARTILE.INC(range,1)  → the 25th percentile ("bottom quarter" cutoff)
=PERCENTILE.INC(range,0.9)  → the value below which 90% of the data falls

Example: "90th percentile response time" is a common ops/DS metric — it tells you the near-worst-case, not just the average.

Correlation — Do Two Things Move Together?

=CORREL(range1, range2)   → a number from -1 to +1

+1 = move perfectly together, -1 = move perfectly opposite, 0 = no relationship. Example: =CORREL(ad_spend_range, sales_range) returning 0.82 suggests a strong positive relationship between ad spend and sales — but remember, correlation is not proof of causation.

Simple Forecasting

=FORECAST.LINEAR(new_x, known_ys, known_xs)   → predicts a future value assuming the past trend continues in a straight line
=TREND(known_ys, known_xs, new_xs)            → same idea, can return multiple predicted points at once

Excel's Data → Forecast Sheet button automates this entirely — pick a date column and a value column, and it draws a forecast chart with confidence intervals for you.

Analysis ToolPak 📘 Good to Know

Enable via File → Options → Add-ins (if not already visible under Data → Data Analysis). Gives you point-and-click Regression, Descriptive Statistics, and more without writing a single formula — a useful stepping stone before moving into dedicated tools like Python, R, or scikit-learn.

11 What-If Analysis ⭐ Frequently Used+ Added Topic

Tools for working backwards from a target, or testing several assumptions quickly, without manually recalculating a whole model by hand each time.

💼 Why your manager cares Manager says: "What sales volume do we need to break even?" or "What happens to profit if costs go up 10%?" The goal: answer "what needs to be true" or "what if this changes" questions fast, during planning and budgeting conversations.

Goal Seek

Data → What-If Analysis → Goal Seek. Answers: "what input do I need to hit this target output?"

Example: you know your fixed costs and profit margin per unit. Goal Seek finds exactly how many units you need to sell to hit a $50,000 profit target — instead of guessing numbers and recalculating by hand.

Data Tables

12 Error Handling ⭐ Frequently Used+ Added Topic

Formulas fail sometimes — a lookup value that doesn't exist, a division by zero. How you handle that failure is the difference between a clean, trustworthy sheet and one covered in red error text.

💼 Why your manager cares A dashboard full of #N/A and #DIV/0! looks broken and unprofessional, even if the rest of the numbers are correct — it quietly undermines trust in your work. The goal: make formulas fail gracefully, especially in anything shared outside your own sheet. 
=IFERROR(formula, value_if_error)   → catches ANY error and shows something clean instead
=IFNA(formula, value_if_na)         → catches ONLY #N/A (e.g. a missed VLOOKUP/MATCH), leaving
                                        other real errors like #DIV/0! visible so you notice them
Example: a clean lookup instead of a scary error 
=IFERROR(VLOOKUP(A2,Table,4,FALSE),"Not Found")

If A2 isn't in the table, the cell shows "Not Found" instead of #N/A — much easier for a manager or teammate to understand at a glance.

Also useful for checking a cell before acting on it: =ISBLANK(cell), =ISNUMBER(cell), =ISTEXT(cell).

13 Macros & VBA Basics 📘 Good to Know+ Added Topic

Automation for repetitive multi-step tasks. Not required to start as a data analyst, but a strong time-saver once you notice yourself doing the exact same steps over and over.

💼 Why your manager cares Manager says: "You do this same 10-step formatting process every Monday — can we speed that up?" The goal: automate repetitive manual work so you spend time on higher-value analysis instead of repetitive clicking.

Recording a Macro

View tab → Macros → Record Macro → perform the manual steps once → stop recording. Excel writes the VBA code behind the scenes for you — no coding required to get started.

Running It Again

Alt+F8 → select the macro → Run. You can also assign it to a button on the sheet for one-click use.

When is it worth it? Any task with the exact same steps every day/week — e.g. reformatting a weekly export the same way each time. Full VBA programming is a deeper skill on its own; recording macros covers most analyst automation needs without writing code from scratch.
